The Real Debugging (2 days)

9 days of build time. 2 of them spent debugging.

The 3 problems that consumed the time:

  • ArgoCD UI access required HTTPS on port 443 with the self-signed cert, not server.insecure: "true"
  • Stale ArgoCD sync cache resolved by hard refresh annotation: argocd.argoproj.io/refresh=hard
  • Docker Bake variable overrides via --set app.args.APP_VERSION did not work as documented

Each fix was 1 line of code. Each took hours of investigation.

Documentation is rarely wrong, but often incomplete.

The shortest fix usually follows the longest read.
