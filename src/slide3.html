The Project

TerraKubePromoter is a 13-resource AWS deployment that demonstrates GitOps delivery on Amazon EKS.

The project consists of:

  • 1 EKS cluster with 2 managed nodes
  • 1 ECR repository for the application image
  • 1 S3 bucket for Terraform state
  • 4 GitHub Actions workflows
  • 4 Kubernetes namespaces with full RBAC
  • 13 ArgoCD-managed resources across 3 environments

Built across 9 days. Total project cost: $74.

The application itself is a deliberately minimal Flask API.

The point of the project is the delivery pipeline, not the workload.
