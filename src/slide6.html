The Promotion Model

Each environment has its own Kustomize overlay.

The same image moves through all 3, but never the same way.

The 3 environments:

  • dev: app-ci.yml updates the overlay automatically on every push to main
  • staging: promote.yml updates the overlay manually with the dev tag
  • production: promote.yml updates the overlay with the staging digest

Production pins by sha256 digest, not by tag.

A digest cannot be re-tagged or replaced silently in ECR.

The image that passes staging is the exact image that runs in production.
