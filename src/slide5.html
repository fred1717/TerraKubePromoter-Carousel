The Architecture

The infrastructure runs in us-east-1, across 2 availability zones.

The components are:

  • VPC with public and private subnets
  • NAT Gateway for ArgoCD's egress to GitHub
  • VPC interface endpoints for ECR, STS, EKS, CloudWatch Logs
  • VPC gateway endpoint for S3
  • EKS cluster on Kubernetes 1.35, AL2023 node group
  • ECR repository with immutable tags and registry-wide scanning
  • S3 bucket for Terraform state with native locking

3 GitHub Actions workflows drive infrastructure, application, and promotion.

The workload is exposed only inside the cluster, via Service ClusterIP.

Image pulls go through VPC endpoints, so the nodes never reach the public internet.
