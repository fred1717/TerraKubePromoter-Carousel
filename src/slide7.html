Security Baseline

Security is not a layer added on top. Every component carries the constraint at provisioning time.

The baseline:

  • GitHub OIDC federation, no static AWS credentials anywhere
  • 3 IAM roles, each scoped to one workflow's needs
  • ECR with immutable tags and SCAN_ON_PUSH
  • Pod Security Standards: restricted on every namespace
  • NetworkPolicy default-deny in every workload namespace
  • S3 backend bucket: versioned, encrypted, public access blocked

Production runs from sha256 digests, not tags.

Least privilege is enforced by Terraform, not by convention.

Every IAM role's permissions are visible in code and reviewable in pull requests.
