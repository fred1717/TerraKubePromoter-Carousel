The Cost-Tagging Failures (1 day)

Cost Explorer can only break down costs by tags that exist on resources at the time the cost is incurred.

Tags applied late do not backfill historical cost data.

The pattern that cost a day:

  • default_tags on the AWS provider does not include the Name tag
  • Resources missing Name appeared as "(no resource)" in the Tag Editor
  • By the time it was noticed, days of cost had been incurred without the project tag
  • Those costs are permanently invisible to per-project Cost Explorer reports

The fix runs forward, not backwards.

Cost tagging is a project-start concern, not a project-end concern.

The opportunity to tag a resource passes the moment it is created.
