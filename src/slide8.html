The Refactor at v0.6.0

The Terraform code shipped through v0.5.0 worked, but the module boundaries were wrong.

The original layout had everything in one root module. The blast radius of a single mistake covered the VPC, the EKS cluster, and the workload manifests at once.

The refactor split the code into 4 modules:

  • network: VPC, subnets, NAT Gateway, VPC endpoints
  • cluster: EKS, node group, OIDC provider
  • registry: ECR with lifecycle and scanning
  • bootstrap: ArgoCD Helm release and the app-of-apps Application

Each module is independently destroyable.

The refactor was not triggered by self-correction but triggered by user challenge:

"It does not look like 'best practice': is it really how the modules should be structured?"
